- 微信云托管环境：`prod-d3gmusgcw6e97148b`

## 方案一：手动部署（推荐，快速上手）

### 1. 创建后端服务

#### 1.1 登录控制台
访问 https://cloud.weixin.qq.com 登录微信云托管控制台

#### 1.2 创建服务
1. 选择环境：`prod`
2. 点击「新建服务」
3. 服务名称：`mall-admin-server`
4. 选择构建方式：**代码仓库构建**

#### 1.3 配置仓库
- 仓库地址：`https://github.com/boringsnail/nichongsha-mall-manage.git`
- 构建目录：`/`（根目录）
- Docker 文件：`Dockerfile`

#### 1.4 配置服务设置
- 端口：`8080`
- CPU：`1核`
- 内存：`2GB`
- 最小实例：`1`
- 最大实例：`5`

#### 1.5 配置环境变量
在「服务设置」→「环境变量」中配置：

| 变量名 | 说明 | 示例值 |
|--------|------|--------|
| `DATABASE_URL` | MySQL 连接串 | `mysql://账号:密码@内网地址:3306/nichongsha` |
| `JWT_SECRET` | JWT 密钥（≥16字符） | `your-strong-secret-key` |
| `WX_APPID` | 小程序 AppID | `wx1234567890abcdef` |
| `WX_APPSECRET` | 小程序 AppSecret | `your-app-secret` |
| `PUBLIC_BASE_URL` | 公网访问地址 | `https://mall-admin-server-xxxx.sh.run.tcloudbase.com` |
| `PAY_PROVIDER` | 支付模式 | `wechatpay-direct` 或 `mock` |

**注意**：
- `DATABASE_URL` 可以从 `ncspetmall` 服务复制
- `JWT_SECRET` 需要生成一个强密钥（建议使用随机字符串）
- `WX_APPID` 和 `WX_APPSECRET` 与小程序相同

#### 1.6 创建服务
点击「确认」创建服务，等待构建完成（约 2-5 分钟）

---

### 2. 创建前端服务

#### 2.1 创建服务
1. 点击「新建服务」
2. 服务名称：`mall-admin-web`
3. 选择构建方式：**代码仓库构建**

#### 2.2 配置仓库
- 仓库地址：`https://github.com/boringsnail/nichongsha-mall-manage.git`
- 构建目录：`/admin-web`
- Docker 文件：`Dockerfile`

#### 2.3 配置服务设置
- 端口：`8080`
- CPU：`1核`
- 内存：`1GB`
- 最小实例：`1`
- 最大实例：`3`

#### 2.4 配置环境变量
| 变量名 | 说明 | 示例值 |
|--------|------|--------|
| `API_UPSTREAM` | 后端服务地址 | `https://mall-admin-server-xxxx.sh.run.tcloudbase.com` |

**注意**：`API_UPSTREAM` 替换为后端服务的实际域名

---

### 3. 配置域名（可选）

#### 3.1 使用默认域名
- 后端：`https://mall-admin-server-xxxx.sh.run.tcloudbase.com`
- 前端：`https://mall-admin-web-xxxx.sh.run.tcloudbase.com`

#### 3.2 绑定自定义域名
1. 进入「自定义域名」
2. 添加域名（需 ICP 备案）
3. 配置 CNAME 解析
4. 绑定到对应服务

## 方案二：GitHub Actions 自动部署

### 1. 配置仓库密钥

1. 进入仓库：`https://github.com/boringsnail/nichongsha-mall-manage/settings/secrets/actions`
2. 点击「New repository secret」
3. 添加以下密钥：

| 密钥名 | 说明 |
|--------|------|
| `WXCLOUD_APPID` | 微信 AppID |
| `WXCLOUD_PRIVATE_KEY` | 微信云服务私钥 |

#### 获取私钥
1. 登录微信云托管控制台
2. 进入「设置」→「密钥管理」
3. 生成或复制私钥

### 2. 触发部署
- 推送代码到 `main` 分支自动触发
- 或手动触发：Actions → 部署到微信云托管 → Run workflow

## 验证部署

- 进入「服务列表」
- 确认 `mall-admin-server` 和 `mall-admin-web` 状态为「服务正常」

### 2. 测试后端 API

```bash
curl https://mall-admin-server-xxxx.sh.run.tcloudbase.com/api/admin/stats
```

### 3. 访问前端
访问 `https://mall-admin-web-xxxx.sh.run.tcloudbase.com`

- 进入「运行日志」
- 查看服务启动日志和错误信息

## 常见问题

### Q1: 构建失败
- 检查 Dockerfile 路径是否正确
- 检查 Node.js 版本是否匹配
- 查看构建日志排查依赖问题

### Q2: 数据库连接失败
- 确认 DATABASE_URL 配置正确
- 检查数据库账号密码
- 确认服务与数据库在同一 VPC

### Q3: 前端无法访问后端
- 检查 API_UPSTREAM 环境变量
- 确认后端服务已正常启动
- 检查 CORS 配置

### Q4: 微信支付配置
- 配置 `WXPAY_MCHID`、`WXPAY_SERIAL_NO` 等
- 或设置 `PAY_PROVIDER=mock` 使用模拟支付

## 部署后配置

### 1. 商家账号初始化
```bash
# 进入服务控制台 → 运行日志 → 查看初始化日志
# 或使用以下命令创建商家账号：
curl -X POST https://mall-admin-server-xxxx.sh.run.tcloudbase.com/api/admin/create-merchant \
  -H "Content-Type: application/json" \
  -d '{"username": "admin", "password": "your-password"}'
```

### 2. 数据库迁移
- 服务启动时会自动执行 `prisma migrate deploy`
- 如有新增迁移，需要重新部署触发

### 3. 数据初始化
- 如需初始化种子数据，运行：
```bash
npx prisma db seed
```
